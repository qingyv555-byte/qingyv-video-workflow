# Method sources

This skill is an original workflow synthesis. It does not redistribute third-party code, templates, or media. The following projects and studios informed specific ideas:

| Source | Borrowed idea |
| --- | --- |
| [Remotion](https://github.com/remotion-dev/remotion) | Deterministic, frame-driven video composition |
| [video-to-ui](https://github.com/mberman84/video-to-ui) | Breaking video into visual elements, layouts, and states |
| [GSAP](https://github.com/greensock/GSAP) | Timeline labels, nesting, overlap, and sequencing |
| [Anime.js](https://github.com/juliangarnier/anime) | Per-property keyframes and SVG motion |
| [Theatre.js](https://github.com/theatre-js/theatre) | Explicit property curves, extrema, and timing inspection |
| [mo.js](https://github.com/mojs/mojs) | Shape, path, burst, and composition vocabulary |
| [Motion](https://github.com/motiondivision/motion) | Per-property transitions and keyframe timing |
| [School of Motion](https://www.schoolofmotion.com/) | Timing, spacing, anticipation, overlap, and follow-through |
| [Ordinary Folk](https://www.ordinaryfolk.co/) | Coordinating design, animation, and sound around one intent |

These sources are conceptual references, not required dependencies. If a task needs a library API, verify the current official documentation and license before using it.
